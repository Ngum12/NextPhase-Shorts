Personal administrative utility

NextPhase Backups

Encrypted server backups for recovery of the privately operated NextPhase Shorts trial.

What this utility does

The server administrator uses rclone to upload encrypted backup bundles to their own Google Drive, then download the copies to verify their integrity.

Google authorization is for the administrator's backup account. This page has no sign-in or file-upload form.

Google Drive access

The requested drive.file permission covers only files created or explicitly opened with this backup application. Backup filenames, sizes and Drive metadata are visible to Google; bundle contents are encrypted before upload.

Read the backup privacy notice for permissions, credential storage, retention and access revocation.
